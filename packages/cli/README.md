# LaunchProof CLI

The official command-line distribution for LaunchProof.

```bash
npm install --global @launchproof/cli
launchproof analyze .
```

LaunchProof performs static inspection by default. `verify` does not execute repository code unless execution is explicitly authorized and a host-approved pinned runner image is supplied.

See the main LaunchProof repository for the security model, policy format, evidence model, limitations, and self-hosted GUI.
